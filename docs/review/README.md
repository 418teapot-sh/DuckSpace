## 왜 남겨두는가

수정 PR 은 **무엇을 고쳤는지**만 말합니다. 여기에는 **왜 그게 문제였는지, 어떤 경로로 터지는지,
왜 그 방법을 골랐는지**가 적혀 있습니다. 나중에 같은 코드를 만지는 사람이 되풀이하지 않도록 남깁니다.

각 문서에는 **"확인했고 문제 없던 것"** 절도 있습니다. 의심스러워 보이지만 실제로는 괜찮은
지점들을 적어둔 것이라, 다음 사람이 같은 곳을 다시 파지 않아도 됩니다.

### ❌ E-02 — 남의 이미지를 "고정" 해서 못 지우게 만들 수 있습니다

**D-01 의 소유 검증에 달려 있습니다.** #100 이 "우리 저장소인가" 만 넣고 "누구 것인가" 를 미뤘기
때문에, 남의 굿즈 URL 을 자기 장식장에 배치해서 **원래 주인의 삭제를 영구히 409 로 만들 수** 있습니다.

데이터 손실은 없습니다(파일이 안 지워질 뿐). 고치려면 **시드 도구가 이미지를 소유자별 경로
(`images/{userId}/`)로 올리도록 바꾼 뒤** 배치 시점 소유 검증을 넣어야 합니다 — 지금 넣으면
시연 시드 100개가 통째로 400 이 됩니다.
